# ONextBox Beta Testing

ONextBox Beta 测试版本发布仓库，用于提前体验新功能、验证问题修复并收集反馈。

The release repository for ONextBox Beta builds, providing early access to new features and fixes for testing and feedback.

> 本仓库仅发布 Beta 安装包，不存放源代码。
>
> This repository distributes Beta APKs only. It does not contain source code.

[项目源码与正式版本 / Source Code & Stable Releases](https://github.com/MiToverG422/ONextBox) · [下载 Beta / Download Beta](https://github.com/MiToverG422/ONextBox_BetaTesting/releases)

## 获取测试版本 / Get Beta Builds

前往本仓库的 **Releases** 下载 Beta 安装包，也可以在 ONextBox 的「关于 → 软件更新 → 更新设置」中开启「加入 Beta 计划」。

Download a Beta APK from this repository’s **Releases**, or enable **Join Beta Program** in ONextBox under **About → Software Update → Update Settings**.

Beta 更新仅推送版本号高于当前已安装版本、且带有 `_Beta` 标识的版本。例如，`17.0.0.45` 可以获取 `17.0.0.47_Beta`。

Beta updates are offered only for versions newer than the installed version and marked with `_Beta`. For example, `17.0.0.45` can receive `17.0.0.47_Beta`.

## 测试须知 / Before You Test

- Beta 版本可能存在功能缺陷、兼容性问题或稳定性问题，不保证适合日常使用。
  
  Beta builds may contain bugs, compatibility issues, or stability problems and may not be suitable for daily use.

- 安装前请备份重要数据，并了解如何在模块异常时停用模块、恢复设备。
  
  Back up important data before installing, and make sure you know how to disable the module and recover your device if problems occur.

- 请阅读对应版本的更新说明，重点测试本次新增或调整的功能。
  
  Read the release notes and focus your testing on newly added or modified features.

- 退出 Beta 计划不会自动降级至正式版本。
  
  Leaving the Beta program does not automatically downgrade your installation to a stable release.

## 问题反馈 / Report Issues

请通过本仓库的 [Issues](https://github.com/MiToverG422/ONextBox_BetaTesting/issues) 反馈问题，并尽量提供以下信息：

Please report problems through this repository’s [Issues](https://github.com/MiToverG422/ONextBox_BetaTesting/issues), including the following information where possible:

- 设备型号及系统版本 / Device model and OS version
- ONextBox、LSPosed 及 Root 方案版本 / ONextBox, LSPosed, and root solution versions
- 相关功能开关与其他已启用模块 / Relevant feature settings and other enabled modules
- 复现步骤、预期结果与实际表现 / Steps to reproduce, expected behavior, and actual behavior
- 截图、录屏或相关日志 / Screenshots, screen recordings, or relevant logs

偶发问题也欢迎反馈，请说明出现频率及发生前的操作。提交日志前，请检查并遮盖隐私信息。

Reports of intermittent issues are also welcome. Please describe how often the issue occurs and what you were doing beforehand. Review logs and redact private information before submitting them.
